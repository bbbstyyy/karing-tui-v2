# ADR 0177 — actual Proxy DNS TCP lookup through Selected SOCKS detour, not direct fallback

- **Status:** proposed M5/T22 bounded real-Core experiment, not full T22 or release.
- **Base:** merged ADR 0176 verified actual local Direct destination UDP DNS on both pinned native Linux architectures, following ADR 0175 Outbound/Node UDP DNS.
- **Envelope:** seventh independent native `docker --network none --cap-drop ALL --security-opt no-new-privileges --user 10001:10001 --read-only` container per amd64/arm64 architecture. Real production Daemon/Unix API, SHA-approved Core; all previous six containers, fourth long-lived synthetic Selected counters and stable `main` untouched.

## Gap and decision

Generated native configuration already binds `ProxyResolverTag` to Selected and inserts `resolve` before `Selected` routing. That proves only the *compiler representation*. The destination's actual DNS question could be absent, could travel directly or fall back to Direct/Node DNS. The acceptance criterion must inspect both the real DNS service and the synthetic Selected SOCKS outbound.

1. Compile/apply/start one exact generation using three existing mixed inbounds, DIRECT FINAL, no user rules, one fixed IP-literal synthetic Selected SOCKS node. Outbound/Node UDP and Direct UDP profiles remain separate numeric-loopback ephemeral local listeners. Add one **Proxy DNS TCP** `127.0.0.1:<ephemeral port>` role/profile; the compiler alone binds its transport `detour` to CurrentSelected. No proxy `detour_target` field in V1, no fallback, Group DNS, public DNS, TUN or subscription/ISP layer.
2. The only allowed Proxy DNS question is `t24-selected.invalid` (and only bounded IN A, AAAA or HTTPS records): a strict local TCP DNS listener validates 2-byte DNS/TCP length, <=512-byte query, exact reserved name and returns A=127.0.0.1/TTL 1s or NODATA. No arbitrary DNS, recursion, public IP, port 53 or external socket. Record independent exact raw QNAME/QTYPE receipts under lock.
3. Extend the existing synthetic SOCKS node **only optionally** to record successful target `(raw DOMAIN, 127.0.0.1, port)` under its counter lock; older fixtures with no opt-in attribute remain identical. The selected SOCKS server allows only the known echo and local Proxy DNS TCP ports. Audit both DNS TCP query receipt and SOCKS destination-port receipt: DNS receipt alone does not establish a detour.
4. Rule:2080 and Direct:2081 first send SOCKS5 DOMAIN `t24-direct.invalid` and require exact local echo + real Direct UDP A receipt with **no** Selected or Proxy DNS activity, and no Outbound/Node DNS activity. Then send Selected:2082 real SOCKS5 DOMAIN `t24-selected.invalid` over a numeric-local client connection. Require one or more Proxy DNS TCP A question receipts, at least one real Selected SOCKS upstream **DNS TCP port** connect, **exactly one** Selected upstream **echo port** connect and exact application echo. Only the two allowed local target ports and no other hostname or DNS role; no refusals or fixture faults. Bounded 1–12 DNS/TCP requests allow legitimate connection reuse.
5. The same approved Core PID, declaration/config revisions, generation and LKG must persist before and after probes. Stop the Core explicitly in `finally`, audit closed inbounds, responder counters, approved Core hash and cleanup. No-Core negative regressions cover strict V1 declaration, invalid/oversized/partial TCP DNS wire framing, other QNAME, absent/wrong DNS A receipts, wrong SOCKS destination port, DNS direct-bypass, role crossing, false app success, Core drift and sanitized diagnostic codes.
6. Accept `T22_AIRGAP_PROXY_DNS_TCP_SELECTED_DETOUR=ok` only from **both** exact-head native amd64/arm64 CI after ordinary tests, Go Race 4/4 and Managed Core Integration succeed. Keep the PR in Draft on any failure.

## Non-claims and unchanged holds

This is test-only Proxy **TCP** DNS via Selected SOCKS; not Group DNS, remote/public DNS, HTTPS/SNI, SOCKS5 UDP ASSOCIATE, GeoIP pre-resolution, CN licensed 28-rule-group/five-layer real resource verification, T20 1,000 reconnects, T25 72h/7d/30d soak, power-loss rollback, Restore/GC or signed stable release. Preserve `T22_HOSTNAME_AND_UDP_VERIFIED=false`, `T24_CN_RULESETS_OR_REMOTE_DNS_VERIFIED=false`, `T20_1000_RECONNECTS_VERIFIED=false`, `T25_72H_7D_30D_SOAK_VERIFIED=false`, `core_distribution=false`, `cn_preset_offline_bundle=false`. Do not alter stable `main` or release Draft PR #1.
