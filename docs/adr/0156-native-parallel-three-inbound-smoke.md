# ADR 0156 — T25 preflight: bounded concurrent three-inbound local forwarding

- **Status:** a six-client / twelve-request native synthetic preflight, **not** a throughput or 72h/7d/30d soak result.
- **Depends on:** ADR 0149–0155, especially a real promoted Applied=LKG Core managed by a running Daemon, supervisor crash/recovery, three explicit start/stop cycles, and a separate Selected synthetic localhost SOCKS5 node.
- **Envelope unchanged:** Linux amd64 and arm64 native CI, all four independently isolated containers, `docker --network none`, nonroot UID, cap-drop ALL/no-new-privileges/read-only root, pinned approved Core binary, ephemeral private SQLite and only numeric `127.0.0.1` TCP endpoints. No TUN, subscription/ISP layer, external DNS/remote proxy, CN SRS or redistributed resource.

## Gap

ADR 0155 confirms repeated explicit Core starts/stops and sequential local Rule/Direct/Selected packet echoes, but it does not exercise overlapping clients in the same applied Core process. In particular, concurrent Rule/Direct connections could be mistakenly sent via Selected or a Selected connection could silently bypass the only permitted synthetic SOCKS node. The test also used simple counters in a threaded synthetic fixture, which must not lose updates when multiple connections overlap.

## Decision

1. On **the third and final** explicit Core start of ADR 0155's existing fifth-Daemon session (same disposable SQLite and approved generation 2), launch exactly **six concurrent local clients**, two workers per inbound `Rule:2080`, `Direct:2081`, `Selected:2082`. A barrier with an 8-second timeout coordinates only the test clients; each worker sends two **different** 127.0.0.1 echo payloads and requires the full SOCKS5 greeting, successful CONNECT and exact echo. Every individual socket has the pre-existing 4-second timeout; the future wait is bounded to 40 seconds per worker. Total is 12 echo requests.
2. Verify all six workers returned the intended entry point, Selected's synthetic SOCKS accept counter increased by **exactly four** with **zero** new rejections and no fixture failure. Every worker sends a unique fixed 32-byte inbound-tagged payload; the synthetic Selected node reconstructs its own received tag across arbitrary TCP read boundaries, records it under the same lock, and must observe **exactly the four expected Selected-only tags**, not merely a compensating cross-route count. Rule and Direct must account for **zero** additional Selected SOCKS node requests even under overlap. The local selected server's accept/reject counters now use an internal threading lock, so the test fixture counts cannot silently lose increments under parallel handling.
3. Re-read real Daemon management status after the concurrent batch and require **unchanged Core PID**, declaration/config revision 2, Applied/LKG generation 2, running intent, no recovery or pending operation. Preserve the existing third stop, no-port-listener assertion, Daemon FD sampling and sixth-Daemon stopped-intent persistence test.
4. Fast stdlib tests mock only the local `probe_port` primitive and verify 12 unique payloads, 4 requests on each inbound and exactly 4 Selected-node hops. Explicit negatives must reject invalid echo ports, missing or unexpectedly extra Selected hops, a node failure, a new refusal, a failed worker and poisoned counter/fixture state; update ADR 0155 lifecycle test to demand the new batch only in cycle 3.
5. Append `T25_AIRGAP_PARALLEL_LOOPBACK=ok` only if the complete real native run succeeds; continue to print `T25_72H_7D_30D_SOAK_VERIFIED=false` and keep all other T24/T25 and CN distribution markers unchanged. Latest-head ordinary test/build, 4/4 Race, real Managed Core integration, and native amd64/arm64 Core Provenance remain the mandatory PR gate.

## Limits

A bounded localhost burst across 12 TCP echoes is **not** measured p99 latency, throughput, connection-duration survival, multi-minute sustained load, DNS/ruleset correctness, actual CN 28 groups and five routing layers, external network resilience, physical host reboot, reliable archive/credentials restore, license clearance, offline distribution, dual rollback, or 72h/7d/30d long soak. T15/T23/T24/T25 release gates stay **OPEN** and Restore/GC remain unavailable; `core_distribution=false`, `cn_preset_offline_bundle=false`, stable `main` untouched and outer PR #1 Draft.
